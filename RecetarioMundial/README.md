# Recetario Mundial

Proyecto básico con HTML, CSS y JavaScript que utiliza TheMealDB.

## Ejecutar localmente
En la terminal, desde esta carpeta, ejecuta `py -m http.server 8000` y abre http://localhost:8000.

## Publicar en GitHub Pages
Crea un repositorio llamado `RecetarioMundial`, luego ejecuta:

```bash
git init
git branch -M main
git add .
git commit -m "Crear Recetario Mundial"
git remote add origin https://github.com/TU_USUARIO/RecetarioMundial.git
git push -u origin main
```

Cambia `TU_USUARIO` por tu usuario de GitHub. En Settings > Pages selecciona GitHub Actions.
